#  Intership Weather-Forecast Web Application



## Funcional Requirements
* Our application enables users to request weather forecasts based on their selected location for the **next 24 hours, 7 days, or 30 days**. It features an interactive interface that displays **temperature, rainfall, wind speed, and weather conditions using dynamic charts and icons**. Users can **maintain a history of their forecast requests** and view them on an integrated map.
* The system supports **user registration, login, and profile management, with each user able to configure default settings** like preferred locations. Behind the scenes, it **fetches and processes raw weather data from external sources**, storing it in a structured and efficient format. Forecasts are enhanced using predictive models with confidence intervals and periodic updates to maintain accuracy.
* The app incorporates measures like **authentication, rate limiting, secure password handling, and activity logging** to ensure a seamless and secure experience. The platform also includes an **admin interface** for monitoring system usage and identifying potential misuse.
